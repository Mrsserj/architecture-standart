| F   | На сайте и в интернет-банке должны отображаться доступные депозиты                                |    На сайте доступны актуальные ставки для новых клиентов. В интернет банке доступны также персонализированные ставки для постоянных клиентов.          |
| F   | На сайте и в интернет банке можно подать заявку на открытие депозита                                |       При заявку через сайт, клиент оставляет номер телефона. Далее оператор колл-центра связывается с клиентом и передает заявку дальше. В интернет-банке заявку можно отправить напрямую в АБС.       |
| F   | Менеджер бэк офиса может обрабатывать заявки, отправленные через сайт. |  Менеджер проверяет заявку, при одобрении, депозит регистрируется через АБС, а клиент получает уведомление через СМС.           | 
| F   | Шифрование при передаче данных через сайт и интернет банк |              |
| U   | Количество шагов, а также количество запрашиваемых данных для открытия депозита должно быть минимальным                                |  Один из важнейших шагов, от которого зависит прибыль банка. На сайте клиент должен ввести только ФИО и номер телефона, в интернет банке только размер депозита и срок хранения.            |
| U   | Скорость обработки заявки должна быть максимальной, не более N часов.                                |              |
| R   | Все сервисы должны работать 24/7, доступность 99,9%.                                |              |
| R   | Обеспечить целостность данных.                                |  Все поданные заявки клиентов должны быть обработаны.            |
| R   | Обеспечить безопасность персональных данных.   | Данные должы использовать шифрование при передаче.             |
| P   | Время отклика должно быть меньше 1 сек.                                |              |
| P   | Использовать горизонтальное масштабирование и распределить запросы клиентов между всеми серверами и ЦОДами.                                |              |

- F    Функциональные (Functionality)
- U    Удобство использования (Usability)
- R    Надёжность (Reliability)
- P    Производительность (Performance)
- S    Поддерживаемость (Supportability)
- +R   Ограничения (Restricitions)
